# 🐾 그리운 마음을 담아 전하는 반응형 편지 카드 (Puppy Letter Card)

강아지 일러스트를 전체 배경으로 활용하여, 따뜻하고 고급스러운 분위기 속에서 진심 어린 편지를 전할 수 있도록 제작된 반응형 웹 카드 프로젝트입니다.

---

## ✨ 주요 특징

* **전체 화면 일러스트 배경 & 글래스모피즘(Glassmorphism)**
  * 강아지 일러스트(`puppies.jpg`)를 화면 전체에 배치하고 은은한 호흡(Zoom) 애니메이션을 적용했습니다.
  * 어두운 반투명 유리 질감의 카드와 금빛 이중 테두리를 더해 편지 글씨가 선명하고 우아하게 읽히도록 디자인했습니다.
* **위에서 아래로 흐르는 편지 애니메이션**
  * 제목부터 각 문단, 맺음말까지 시간차를 두고 위에서 아래로 부드럽게 내려오며 나타납니다.
  * 우측 상단의 **`↻ 다시 읽기`** 버튼을 누르면 애니메이션을 언제든 처음부터 다시 감상할 수 있습니다.
* **감성적인 하트 & 빛줄기 효과**
  * 화면 상단에서 비추는 따뜻한 햇살 빛줄기(CSS)와 아래에서 위로 천천히 떠오르는 반투명 하트 및 금빛 입자(HTML5 Canvas)가 어우러져 애틋한 분위기를 연출합니다.
* **내장 오르골·피아노 멜로디 (`음악 켜기`)**
  * 별도의 MP3 음원 파일 없이 브라우저 내장 **Web Audio API**를 통해 따뜻하고 잔잔한 F 장조 선율을 실시간으로 연주합니다. 오프라인 환경에서도 정상 작동합니다.
* **모바일 완벽 반응형 지원**
  * 데스크톱, 태블릿, 스마트폰 등 기기의 화면 크기에 맞춰 여백, 카드 위치, 폰트 크기가 자동으로 최적화됩니다.

## 📁 폴더 및 파일 구조

```text
puppy_letter_card/
├── index.html      # 편지 카드 메인 웹페이지 (HTML, CSS, JS 통합)
├── puppies.jpg     # 전체 화면 배경으로 사용되는 강아지 일러스트 이미지
└── README.md       # 프로젝트 설명서
```

---

## 🚀 사용 방법

1. 압축을 해제한 폴더 안의 **`index.html`** 파일을 더블 클릭하여 웹 브라우저(Chrome, Safari, Edge 등)로 엽니다.
2. 편지 내용을 감상하며 우측 상단의 **`음악 켜기`** 버튼을 클릭하면 잔잔한 배경 멜로디가 재생됩니다.
3. 다른 사람에게 공유하고 싶다면 폴더 전체를 웹 호스팅(GitHub Pages, Netlify, Vercel 등)에 업로드하여 링크로 전달할 수 있습니다.

## ✏️ 편지 문구 및 배경 수정 가이드

### 1. 편지 내용 바꾸기
`index.html` 파일을 메모장이나 코드 에디터(VS Code 등)로 연 뒤, 아래 부분을 찾아 원하는 문구로 수정하세요.

```html
<h1 class="letter-title">문득 네가 떠오르는 따뜻한 날에</h1>

<div class="letter-body">
  <p class="letter-line">
    첫 번째 문단 내용을 입력하세요.
  </p>
  <!-- 필요한 만큼 <p class="letter-line"> 태그를 수정하거나 추가할 수 있습니다. -->
</div>

<div class="letter-sign">언제나 네 편인 사람이</div>
```

### 2. 배경 이미지 교체하기
* 다른 이미지를 사용하고 싶다면 새 이미지 파일의 이름을 `puppies.jpg`로 변경해 덮어쓰거나, `index.html` 내의 `.bg-image` 스타일에서 `background-image: url('파일명.jpg');` 경로를 수정하면 됩니다.

## 🛠️ 사용 기술

* **HTML5** (시맨틱 마크업 & Canvas API)
* **CSS3** (Glassmorphism, Keyframe Animations, Flexbox, Media Queries)
* **Vanilla JavaScript** (Web Audio API 사운드 합성, 파티클 애니메이션)
* **Google Fonts** (`Gowun Batang`, `Nanum Myeongjo`)
